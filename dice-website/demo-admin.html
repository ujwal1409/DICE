Reviews the demonstration RFQ submissions saved by this prototype in your own browser. Nothing here was received by DICE.

This page has no authentication

This is a local demonstration interface, not a real secure administrative system. Please read this before using it for anything.

  • There is no login and no access control. There is deliberately no sign-in screen, because a prototype with no server cannot actually protect anything — a fake login would imply security that does not exist.
  • It must not be used for real customer data. Anything stored here sits unencrypted in this browser's local storage and is readable by anyone with access to this device or its developer tools.
  • These are not real customer submissions. Every record was created by whoever filled in the RFQ form in this browser. None of them reached DICE, and none represents a genuine enquiry.
  • No documents were ever uploaded. Only filenames and byte sizes were recorded. File contents were never read, transmitted or stored.
